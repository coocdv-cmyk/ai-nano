## 1. What was investigated

The four unresolved failures reported by EXP-J, plus their interactions:

1. Deep-composition incorrect acceptance.
2. OOD retrieval silent substitution.
3. Drift-detection failures.
4. Confidence-calibration failure.

This was a root-cause campaign, not benchmark optimization. Every treatment was
compared with a **matched baseline** built from the same constructors, seeds,
splits and configuration. Test labels were used only by the evaluation side,
after decisions were made.

## 2. K0 — Baseline and reproducibility

EXP-J reference failures were reproduced on EXP-K's independently generated
families (not compared as if they were the same datasets):

| Failure | EXP-J reference | EXP-K baseline |
|---|---|---|
| Deep-composition incorrect acceptance | 105/280 = 0.375 | **39/70 = 0.557** |
| Retrieval silent substitution | 1.00 | **0.40** in K0; **1.00** in K2's type-matched probe |
| Drift missed streams | 0.60 | **0.575** in K0; 0.793 in K3's wider drift matrix |
| Independent ECE | 0.1596 | **0.1699** (K0); **0.1258** (K4 held-out split) |

Deliverables: seed registry, `k0_dataset_manifest.json` (800 clean datasets),

## 3. K1 — Deep-composition root causes (350 runs)

- Incorrect acceptance is **not** caused by timeouts (0) or representation
  limits (all chains are in-DSL). It is a validation blind spot: programs that
  merely fit support/validation are accepted as if semantically correct.
- First-error tracing found the earliest divergence at composition step **2**
  (median), confirming error propagation.
- Three deployable safeguards (shifted validation, CEGIS, conservative
  abstention) each cut incorrect acceptance from **0.557 to 0.329** on 70 paired
  episodes (41% relative), but **abstention tripled (0.443 → 0.671)** and
  correct acceptance stayed 0.000. CEGIS cost 64% more expansions for no extra
  benefit.
- An oracle intermediate-contract arm reached 0 incorrect acceptance but
  abstained on everything — an explicit non-deployable upper bound.
- **Conclusion:** cause confirmed, fix not achieved. Safety was purchased with
  coverage, not generated by better composition.

## 4. K2 — OOD retrieval (720 queries)

- Baseline silent substitution on type-matched held-out families: **1.000** —
  the EXP-J result is fully reproduced.
- Type-aware ranking alone changed nothing; the "missing type constraint"
  hypothesis is **rejected**. The cause is behavioral-similarity collision
  without an OOD rule.
- OOD rejection / ambiguity abstention cut substitution to 0.02;
  provenance-compatible and independent-verification arms reached **0.000** —
  but familiar-family correct top-1 fell from **0.867 to 0.333–0.367**.
- **Conclusion:** the top-ranked candidate is never automatically correct; the
  tested safeguards convert silent errors into honest abstentions at a large
  coverage cost. Retrieval latency (<0.3 ms) is not the limiting factor.

## 5. K3 — Drift detection (2,400 stream-arm rows)

| Arm | Recall | Miss | False alarms (stable) |
|---|---|---|---|
| Acceptance baseline | 0.207 | 0.793 | 0.325 |
| Accuracy window | 0.184 | 0.816 | 0.225 |
| **Feature window** | **0.998** | **0.002** | **0.000** |
| Two-window | 0.868 | 0.132 | 0.000 |
| Combined | 0.998 | 0.002 | 0.225 |

- Accuracy-based detection fails because validation accuracy is often *higher*
  during drift (0.992) than before it (0.845): the rule remains valid off-domain.
- A simple input-feature statistic with thresholds fixed on calibration seeds
  (101–103) detects 99.8% of drift with zero stable-stream false alarms. This is
  the clearest positive result.
- **Caveat:** all twelve named drift kinds were implemented as input-domain
  moves; genuine semantic/concept drift with unchanged inputs was not modeled.
  The result applies to feature/parameter drift only.

## 6. K4 — Calibration (140 calibration + 350 held-out rows)

| Method | ECE | Brier | NLL |
|---|---|---|---|
| raw | 0.1258 | 0.0841 | 0.2840 |
| temperature (T=0.75) | **0.0741** | 0.0770 | 0.2639 |
| isotonic | 0.0982 | **0.0679** | 0.8983 |
| binning | 0.0842 | 0.0768 | **0.2620** |

- Post-hoc transforms reduce ECE but **never change accuracy (0.491)**.
  Isotonic overfits 140 calibration rows and destroys NLL.
- Calibration fails where it matters: deep compositions ECE 0.424 (temperature
  makes it worse), retrieval substitutions 0.410. Contradictory cases are
  trivially calibrated at confidence 0.
- **Conclusion:** confidence is a heuristic blend, not a posterior; predictive
  confidence is not proof of correctness.

## 7. K5 — Cross-mechanism interactions

13 regressions were recorded over 10 factorial pairs. The most damaging is
`evidence_validation + deep_search`: correct acceptance and coverage both fall.
`noisy_evidence + deep_search` loses coverage. Adding resource governance to
CEGIS reduces coverage and increases expansions. Several OOD/drift-source cells
were **saturated and uninformative** because the evaluation core did not engage
the toggles; they are preserved but must not be quoted as positive findings.

## 8. K6 — Adversarial reliability (240 rows, 12 attacks)

Useful coverage: **0.408** for the system vs **0.000** for an always-abstain
control — the system is not merely refusing everything. Non-composition attacks
(misleading positives, correlated support, missing counterexamples, near-identical
rules, noise, contradictions, unseen families, misleading neighbors, abrupt
change) all show zero incorrect acceptance. Every unsafe case is compositional:
incorrect intermediate 0.30, deep deceptive 0.40, resource exhaustion 0.40.
One K6 run initially failed on an `abs()`-on-list generator bug; the failed
snapshot was preserved, the bug fixed, and the rerun reported.

## 11. What improved, what did not, what remains unknown

**Improved/validated:** four failure conditions reproduced on independent data;
drift detection solved for feature drift; ECE reduced by temperature/binning;
retrieval safety achievable via independent verification; system provides real
useful coverage under adversarial conditions.

**Not fixed:** deep-composition incorrect acceptance (correct discovery remains
zero in all K1 arms); retrieval coverage/safety trade-off; calibration on deep
and retrieval-substitution cases; cross-mechanism regressions.

**Rejected hypotheses:** "missing type constraints cause retrieval
substitution"; "accuracy-based drift detection is sufficient"; "post-hoc
calibration fixes decision quality".

**Unknown:** genuine semantic/concept drift with unchanged inputs; natural-input
behavior; whether a deployable intermediate verifier can restore coverage;
statistical significance of interaction terms.

**Next experiment:** test a deployable (no-oracle) intermediate verifier on
composition, with semantic drift environments where input features are unchanged,
and a factorial design whose OOD/drift mechanisms actually engage decisions.
